## Design and implementation plan

One branch/PR, preserving all experiments. Add compact provider-neutral AGENTS.md and
Claude pointer; review rubric; one detailed operating model; one stdlib source selector;
an exact-head read-only-by-default merge helper; negative-case tests; a read-only PR/main
gate and a separate no-checkout repair-intent workflow. No dependency bootstrap or paid
AI calls. The PR template links existing authority rather than duplicating it.

Proof must cover malformed/unknown/renamed/deleted inputs, dirty/mismatched heads,
missing contracts, stale/forged/failed gates, stale/negative/untrusted review records,
unresolved threads, pagination and maintenance deduplication/stale-event handling.
Inspect the exact GitHub-published file hashes, observe CI, record a truthful exact-head
review, merge with SHA guard and verify main plus preservation of experiment refs.

Non-goals: fishing fixes, merging experiment code, real provider requests, screen/audio
capture, mouse/keyboard control, Mac installs/permissions/accounts, changing server
protection, spending, releases or provisioning an unattended agent. Linux/offline proof
must not be called live macOS evidence. A revert PR is the source-policy rollback;
no machine rollback is required because no machine effect is performed.

## Evidence location

The adopting PR, its exact-head review and GitHub Actions runs are the execution record.
Local isolated checks are supplementary; remote CI proves the actual published head.
The manifest measures the deterministic gate only. No author token usage or performance
improvement is claimed without measurement. Maintenance failure paths are fixture-tested;
a successful main run alone does not prove that a live failure issue has been created.
